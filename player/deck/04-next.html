Механика Четыре препятствия

Проблемы компиляции PHP

  1. 01

    Целочисленная арифметика

    При переполнении результат операции с int становится float.

  2. 02

    Динамические имена и код

    $$var, имена функций и классов, eval() определяются только при исполнении.

  3. 03

    Обход PHP-массива

    foreach должен учитывать пустые ячейки, ссылки и изменение массива.

  4. 04

    Вызов метода

    Способ вызова зависит от класса, интерфейса и формы имени метода.

// машинный код должен сохранить поведение исходной программы

Проекты Устройство систем

Четыре подхода компиляции

  1. JIT

    PHP → трасса → машинный код

    Работает внутри Zend и всегда может вернуться в VM.

  2. KPHP

    PHP → C++ → бинарник

    Анализ всей программы и собственный рантайм.

  3. TypePHP

    PHP → C++ → расширение

    Скомпилированный модуль загружается в обычный PHP.

  4. AOT

    PHP → IR → машинный код

    elephc и Manticore не используют Zend при исполнении.

elephc eval без Zend

Как elephc справляется с динамикой

  1. PHP

    Обычный код → EIR → assembly

    Поддерживаемые конструкции исполняются как машинный код.

  2. eval

    Известная строка → тот же AOT

    eval('echo 1 + 1;') можно разобрать ещё при сборке.

  3. EvalIR

    Динамическая строка → Magician

    Собственный интерпретатор на Rust встраивается в бинарник.

  4. ≠ Zend

    Общий runtime приходится написать самим

    Scope, значения, COW, функции, классы и исключения пересекают границу.

// AOT + interpreter fallback · «без Zend VM» не означает «без runtime»

Управление памятью и GC

Освободить быстро. Не освободить рано. Найти циклы.

PHP Три связанных механизма

Refcount решает не всю задачу

  1. RC

    Последняя ссылка освобождает сразу

    Предсказуемое время жизни и своевременный вызов деструктора.

  2. COW

    Копия массива откладывается до записи

    Присваивание дёшево, но уникальность приходится проверять.

  3. GC

    Цикл сохраняет ненулевые счётчики

    Нужен отдельный поиск недостижимых компонент графа.

// RC отвечает «сколько ссылок» · GC — «достижимо ли значение от корней»
