Механика Устройство систем

Четыре конвейера компиляции

  1. JIT

    PHP → трасса → машинный код

    Работает внутри Zend и всегда может вернуться в VM.

  2. KPHP

    PHP → C++ → бинарник

    Анализ всей программы и собственный рантайм.

  3. TP

    PHP → C++ → расширение

    Скомпилированный модуль загружается в обычный PHP.

  4. AOT

    PHP → IR → машинный код

    elephc и Manticore не используют Zend при исполнении.

    Способ вызова зависит от класса, интерфейса и формы имени метода.

JIT Горячая трасса

А как это делает JIT?

  1. 01

    Интерпретация

    Сначала код исполняет виртуальная машина Zend.

  2. 02

    Профилирование

    JIT записывает типы и цели вызовов на горячем участке.

  3. 03

    Специализация

    Для наблюдавшегося сочетания строится машинный код.

  4. 04

    Боковой выход

    Другой тип возвращает исполнение в Zend VM.
