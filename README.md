# PHP и компиляция

Материалы доклада о компиляторах PHP: зачем их создают, какие части семантики PHP мешают AOT-компиляции, откуда берётся ускорение и чем приходится платить за него.

## Запуск презентации

Слайды загружаются через `fetch`, поэтому презентацию нужно открывать через локальный HTTP-сервер:

```powershell
python -m http.server 8000
```

После запуска откройте <http://localhost:8000/player/>.

## Структура

- `player/` — браузерный плеер, темы и слайды;
- `dev/script/` — сценарий доклада;
- `dev/research/` — исследования и источники;
- `bench/` — код и результаты измерений.

Порядок файлов колоды задан в `data-parts` внутри `player/index.html`. Заметки докладчика хранятся в атрибуте `data-speaker-notes` каждого слайда.

Схемы TypePHP, elephc и Manticore нарисованы на Canvas. Пробел или стрелка
вправо раскрывает следующий этап; стрелка влево возвращает предыдущий.
После последнего этапа следующий пробел переключает слайд. В обзоре и
при печати схемы показаны целиком.

Тема «Пыхник’26» выбрана по умолчанию: логотип и цвета конференции,
фирменный шрифт в заголовках. Остальные темы доступны в меню или клавишей T.
Ранее сохранённый выбор темы сохраняется; чтобы включить новую тему в таком
браузере, выберите «Пыхник’26» в меню. Все 13 иллюстраций активной колоды
получили отдельные версии в палитре конференции с элементами «Матрицы».
Прежние темы сохраняют исходные картинки. Логотип, шрифт и изображения
хранятся локально. На финальном слайде — QR-код сайта конференции.
