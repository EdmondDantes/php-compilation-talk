# PHP и компиляция: для чего? — исходники деки

Откройте index.html в браузере. Ничего собирать не нужно.

    index.html            32 слайда: <section class="slide …"> внутри <deck-stage>
    css/industry.css      дизайн-система Industry: токены (--color-*, --font-*) и компоненты
    css/deck.css          грамматика слайдов этой деки (только раскладка, цвета берутся из токенов)
    js/deck-stage.js      сцена: масштабирование, навигация, лента слайдов, заметки, печать

## Как это устроено

Поле слайда — x 120..1800, y 120..960 при размере сцены 1920×1080.
Базовый шаг 48px. Нарисованы только реперные метки по углам поля и линейка
под заголовком; вся остальная сетка задаёт координаты, но не рисуется.

Классы раскладок в css/deck.css: .cover .divider .content .rows .cards .chain
.layers .matrix .proj .specs .term .plot .table.compact .hero-num .plate.

## Навигация

    ← →  или пробел   слайд вперёд/назад
    T                 лента слайдов
    Cmd/Ctrl + P      печать: один слайд на страницу

## Правки

Текст — прямо в index.html. Цвета и шрифты — переменные в начале css/industry.css.
Размеры типографики деки — блок deck-stage { --type-* } в начале css/deck.css.
Кегли ниже 24px на слайде 1920×1080 не используются.

Кириллица: в Barlow её нет, поэтому стек — Barlow (латиница, цифры) с падением
на Fira Sans Condensed / Fira Sans для кириллицы. Терминальная плита — Fira Mono.

Заметки докладчика лежат в атрибутах data-speaker-notes у каждого слайда.
Пометки «данные-заглушки» стоят на слайдах 16 и 29 и в сноске таблицы 17 —
их надо снять, когда появятся реальные замеры.
